# Copy trading (live, 2026-10-23)

A follower picks a public trader ("leader") on SoDEX or Hyperliquid, sets their
own rules, and copies run on **SoDEX perps in the follower's own account**, with
a key the follower registered there. ValueDesk never holds funds.

## Three modes, one engine

| | This browser | ValueDesk executor (hosted) | Self-hosted |
|---|---|---|---|
| Runs | in an open ValueDesk tab (one tab per browser holds a Web Lock) | `valuescan-executor` on the Tokyo instance, 24/7 | `valuedesk-copier.mjs` (or Docker) on the follower's machine |
| Copy key | `vd-copy-browser`, generated in the browser, vault slot `copy`, max 7 days | `vd-copy-tokyo`, generated by the executor, AES-256-GCM sealed (`kek` file), max 90 days | `vd-copy-self`, generated by the copier, sealed in `copier-data/`, max 90 days |
| Key engine | perps only | perps only | perps only |
| Instructions | clicks in the tab | EIP-712 `CopyRequest` signed per change, kept append-only | EIP-712 `CopyRequest`, kept by the copier |
| Leader feed | SoDEX `trade` stream (bi/si), Hyperliquid `userFills` | SoDEX `trade` stream, Hyperliquid `trades` on every coin | SoDEX `trade` stream, Hyperliquid `userFills` |
| Reached by the site | itself | `/api/copy/v1/*` (Vercel edge -> Caddy -> 127.0.0.1:8799) | `http://127.0.0.1:<port>/api/copy/v1/*` (loopback only, CSP) |

The engine is `packages/copy-engine` (MIT): settings, the region policy and the
copy fee ladder (`policy.ts`), the planner (`planner.ts`), the SoDEX and
Hyperliquid clients, the feeds, order sinks (`KeySink`, `PaperSink`), the runtime
and the signed API contract (`api.ts`). The executor is `apps/executor` (MIT):
`node:http`, `node:sqlite`, no framework. The web side is `apps/web/src/copy/`
(`live.ts` is the store over the three modes, `browserCopier.ts` mode 1,
`executor.ts` the API client, `sodexSetup.ts` the SoDEX signatures,
`CopySetupSheet.tsx` the setup sheet and its steps) and the Copy page in
`apps/web/src/components/copy/`: the trader grid (`Discover.tsx`, `TraderCard.tsx`,
`gridModel.ts`) with the copy score (`copyScore.ts`: 30 profit, 25 return, 20 win
rate, 15 account size, 10 track record, from the public board figures; a losing
trader at most 35; shown with "not a recommendation"), the two-step copy dialog
(`CopyModal.tsx`: rules with a replay of the trader's fills, then where it runs,
the amount and the mode's signatures), one trader's page and My copies
(`panels.tsx`).

### What a copy does

- Every leader position change (stream print, coalesced 150 ms per market, or a
  1-minute REST reconcile) is planned per follower: target by notional
  (proportional / fixed ratio / fixed amount), increases never shrink, decreases
  follow the leader's fraction, flips close then reopen.
- Caps in order: max position, gross leverage (the lowest of the follower's cap,
  the **EEA 2x cap**, the market's), market order limits, step, minimum notional.
- Orders are IOC limits at the SoDEX mark +/- the slippage cap, inside SoDEX's
  band; every follower of an event gets the same reference price, in random order.
- Positions open when copying starts are left alone until the leader is flat
  (unless "copy existing"); a market the follower holds by hand is left alone.
- Stop-loss / take-profit: copier-side at the marks AND as SoDEX position stops
  (reduce-only, mark trigger) so they hold while no copier runs; drawdown stop
  halts the copy.
- A live copy is `blocked` (and resumes by itself) without a registered key, a
  builder approval of at least 0.025%, or an allowed region.
- Signed writes are never retried; the account is re-read after orders and every
  30 s, and the copy's books follow what SoDEX says. Fills come from the public
  stream by the follower's account id.
- Paper copies run the same way against the live leader and send nothing.

## Owner decisions (2026-10-23)

- Hosted executor **live for every allowed country**.
- Copy fee: the copy ladder on **every** copied order in every mode -
  2.5 bp under $100k of 14-day volume, 2 bp from $100k, 1.5 bp from $500k,
  1.2 bp from $2M, 1 bp from $10M. Followers approve a 0.025% ceiling on SoDEX.
- Blocked: US + territories (US PR VI GU AS MP UM), CU IR KP SY RU BY MM.
  EEA residents (EU + IS LI NO): copies capped at 2x. The stricter of the
  declared country and the IP country (hosted, Vercel `x-vercel-ip-country`) applies.

## Legal safeguards built in

What the product does for its users before and during a copy.

1. **Terms before any copy**: `/copy-terms` (legal/copyTerms.ts, version
   `2026-10-23`), accepted by ONE wallet signature carrying the version, the
   keccak256 of the exact text, the declared country and four statements (adult;
   not a US person; chose the trader and every rule themselves; read the risks).
   ValueDesk's executor records every acceptance, in every mode.
2. **Every instruction signed and kept**: subscribe, update, pause, resume, stop,
   stop all, key create/delete - each an EIP-712 message the wallet displays as
   readable JSON, verified (signer, executor id, deadline, nonce) and stored
   append-only before it takes effect (`consents` table). Followers can read
   their own record (`GET /api/copy/v1/consents`).
3. **No personal recommendation**: traders shown by public, objective metrics,
   the same for everyone; no "suggested for you"; "Not investment advice" next
   to the start button; past performance caveats in the backtest and the terms.
4. **The follower decides everything**: leader, sizing, caps, stops, coins,
   margin mode; the executor never changes a rule; optional "ask before each
   trade" in browser mode; paper mode to try a rule without orders.
5. **Regions**: declared country required; IP country checked by the hosted
   executor; blocked countries refused at terms, at start and at runtime
   (`blocked`); EEA 2x cap enforced by the planner and on the SoDEX position
   leverage in every mode.
6. **Key hygiene**: copy keys are perps-only, separate from the trading key,
   short-lived (7 / 90 days), named per mode (re-approving replaces, never adds),
   sealed at rest; the hosted-key notice discloses that a SoDEX trading key can
   also move funds between the follower's own accounts; revoke in one click.
7. **Kill switches**: pause / stop per copy, stop all (every mode), stop and
   close, revoke the key on SoDEX (the hard stop), drawdown stop.
8. **Transparency**: activity log per copy (sent orders with limit price, actual
   fills, skips with reasons, status changes, errors), CSV export, fee per order.
9. **Fairness**: same limit price for all followers of an event, random order,
   no paid priority, no inducements to or from leaders; leaders are not paid.
10. **Self-host and browser modes are software the follower runs**: open source
    (MIT), the follower's key never reaches ValueDesk, the site talks to a
    self-hosted copier over loopback only.
11. **Privacy**: the policy covers what each mode processes, where (Vercel hnd1,
    AWS ap-northeast-1, Japan adequacy decision), legal bases and retention
    placeholders; the executor never stores IP addresses.

  to ship while any is left.

  (filling a placeholder is a change): followers then sign again.

## Run it locally

```
node scripts/with-node.mjs --prefix apps/server run dev      # API :8797
node apps/executor/tools/dev.mjs                             # executor (hosted mode) :8799, data in %LOCALAPPDATA%/Valuescan/executor-dev
node scripts/with-node.mjs --prefix apps/web run dev         # site :5180, /api/copy -> :8799
cd apps/executor && npm start                                # a self-hosted copier :8799 (or PORT=...)
```

(`npx tsx --test test/*.test.ts`, 9), `apps/web/src/copy/copy.test.ts`,
`apps/web/src/legal/*.test.ts`.
